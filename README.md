# Estação Móvel de Água

Unidade móvel solar de tratamento de água por osmose reversa. O reboque chega à indústria, capta a água bruta do poço, trata, enche a caixa de água tratada e segue para o próximo cliente.

**Site:** https://paulomatiasxvs.github.io/estacao-movel-de-agua/

| Página | O que tem |
| --- | --- |
| [Início](https://paulomatiasxvs.github.io/estacao-movel-de-agua/) | Vídeo, imagens e todos os arquivos para baixar |
| [Modelo 3D](https://paulomatiasxvs.github.io/estacao-movel-de-agua/visualizador.html) | O arquivo .glb aberto no navegador, com a animação |
| [Animação interativa](https://paulomatiasxvs.github.io/estacao-movel-de-agua/animacao.html) | Etapas, fluxos de água e detalhes de cada equipamento |

## Arquivos (pasta `arquivos/`)

- `Estacao-Movel-de-Agua-animado.glb` — modelo 3D com a animação completa (52 s)
- `Estacao-Movel-de-Agua-SketchUp-DAE.zip` — modelo para SketchUp (.dae + texturas)
- `Estacao-Movel-de-Agua-OBJ.zip` — modelo universal (.obj + .mtl + texturas)
- `Estacao-Movel-de-Agua-FullHD.mp4` e `Estacao-Movel-de-Agua-WhatsApp.mp4` — vídeo da operação
- `imagens/` — sete imagens 4K, uma por etapa

## Como abrir o 3D

- **Navegador:** página *Modelo 3D* acima, ou arraste o .glb para https://3dviewer.net
- **Windows:** Visualizador 3D, botão ▶ na barra inferior
- **Blender (grátis):** Arquivo → Importar → glTF 2.0; barra de espaço toca a animação

Valores de referência para apresentação; a animação é acelerada.
